# Пример проекта для платы Saylinx

## Основная информация

- ПЛИС: ALTERA Cyclone IV EP4CE6F17C8
- Отладочная плата: Saylinx
- САПР: Quartus Prime 21.1.1 Lite Edition

## Структура проекта

- [`\docs\ALTERA_EP4CE6F17C8_Datasheet.PDF`](\docs\ALTERA_EP4CE6F17C8_Datasheet.PDF) - документация на микросхему ПЛИС
- [`\docs\Saylinx_scheme.pdf`](\docs\Saylinx_scheme.pdf) - принципиальная схема подключения ПЛИС и элементов на плате Saylinx
- [`fec_saylinx_board_top.qsf`](fec_saylinx_board_top.qsf) - (Qualtrics Survey File) содержит все настройки проекта и распиновку входных/выходных сигналов.
- [`fec_saylinx_board_top.qpf`](fec_saylinx_board_top.qpf) - (Qualtrics Project File) является главным файлом проекта. Необходим для запуска проекта в Quartus Prime Lite Edition.
- [`fec_saylinx_board_top.v`](fec_saylinx_board_top.v) - содержит модуль верхнего уровня.

## Правила безопасности при работе с платой

1. Для подключения платы к ПК:
    1. Убедиться, что переключатель питания в положении OFF;
    2. Подключить плату к ПК с помощью кабеля и разъема mini-USB;
    3. Подключить USB-Blaster к разъему JTAG на отладочной плате;
    4. Переключить переключатель питания в положении ON;
    5. Подключить USB-Blaster к ПК.
2. Не перемещать ВКЛЮЧЕННУЮ плату в руках.
3. Не вытаскивать заглушки с пинов, отмеченных на изображении. 

    ![Не вытаскивать заглушки](docs\imgs\Не_трогать_пины.JPG)

### Тактовый сигнал

Является входным сигналом. Используется для тактирования последовательностной логики. Тактовый сигнал подключен к пину ПЛИС с номером E1.

### Сигнал сброса

Является входным сигналом. Используется для сброса модулей Verilog в начальное состояние. Сигнал сброса подключен к пину ПЛИС с номером N13.

**ОБРАТИТЕ ВНИМАНИЕ**: Сигнал сброса является сигналом с активным низким уровнем. Это означает, что при нажатой кнопке на входной пин подается низкий уровень сигнала, а при не нажатой - высокий уровень сигнала.

### Кнопки

Являюся входными сигналами. Используются для ввода пользовательской информации. Кнопки KEY2, KEY3, KEY4 подключены к пинам ПЛИС с номерами M15, M16, E16 соответственно.

**ОБРАТИТЕ ВНИМАНИЕ**: Сигнал с кнопок являются сигналами с активным низким уровнем. Это означает, что при нажатой кнопке на входной пин подается низкий уровень сигнала, а при не нажатой - высокий уровень сигнала.


### Светодиоды

Являюся выходными сигналами. Используются для вывода пользовательской информации. Светодиоды, подписанные на плате как LED0, LED1, LED2, LED3 подключены к пинам ПЛИС с номерами E10, F9, C9, D9 соответственно.

### Семисегментный индикатор

Являюся выходными сигналами. Используются для вывода пользовательской информации.

Для управления семисегментным индикатором используется 2 сигнала: SEG_SEL - сигнал включения/выбора отдельного индикатора, SEG_DATA - сигнал включения/выбора отдельных сегментов одного индикатора. 

Подробнее изуть способ управления семисегментным индикатором можно в [видео](https://www.youtube.com/watch?v=aLgDQIL-e2Y&t=525s).

**ОБРАТИТЕ ВНИМАНИЕ**: Сигналы к семисегментным индикаторам являются сигналами с активным низким уровнем. Это означает, что при подаче низкого уровня сигнала на выходной пин индикатор/сегмент включается/выбирается, а при подаче низкого уровня сигнала на выходной пин индикатор/сегмент включается/выбирается.

### GPIO

Могут быть выходными или входными сигналами.

В данном курсе предлагается разделить все GPIO поровну на [2 группы](docs\imgs\GPIO_group.png):
- В первую группу (input_pullup) включаются GPIO из разъема J1 и J2 из линии 1. Все GPIO 1ой группы настраиваются как входные пины с подтяжкой к высокому уровню сигнала (если к GPIO с подтяжкой ничего не подключено, то внутренняя логика будет видет 1 на входе).
- Во вторую группу (out_zero_value) включаются GPIO из разъема J1 и J2 из линии 2. Все GPIO 2ой группы настраиваются как выходные пины с жестким вывод низкого уровня сигнала.

В результате такая схема подключения GPIO позволяет использовать их в качестве переключателей для подачи входных данных. 

Например:
- Для подачи высокого уровня сигнала на GPIO_0_input_pullup[0] необходимо оставить пин ПЛИС с номером P1 без подключения к другим пинам.
- Для подачи низкого уровня сигнала на GPIO_0_input_pullup[0] необходимо установить перемычку между пинами ПЛИС с номерами P1 и N2.

Номера пинов ПЛИС можно посмотреть на обратной стороне отладочной платы.

**ОБРАТИТЕ ВНИМАНИЕ**: На обратной стороне отладочной платы пин ПЛИС с номером J16 на самом деле является пином ПЛИС с номером С2. Ошибка в печате изображения на плате.

Пины, отмеченные как UNUSED, это 3v3 и GND.
